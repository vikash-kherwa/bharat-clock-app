# Bharat Clock App

## 🚀 Live Demo

https://vikash-kherwa.github.io/bharat-clock-app/

A simple React app that displays the current date and time in real-time.

Built using React, Bootstrap, and JavaScript.

---

## 🔧 Features

- Real-time clock updates every second
- Displays current date and time
- React Hooks usage
- Bootstrap styling
- Component-based structure

---

## 🛠️ Tech Used

- React
- JavaScript
- Bootstrap
- CSS

## ▶️ How to Run

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
